## 三、P1 严重问题精选（按领域）

### 3.1 安全（14项核心）

1. **nodemailer <=8.0.4 存在SMTP命令注入和DoS漏洞** (CWE-93/CWE-703) — 需升级>=8.0.9
2. **tar传递依赖存在多个高危路径遍历漏洞** (CWE-22) — 需npm audit fix
3. **vite<=6.4.1路径遍历** + **esbuild<=0.24.2开发服务器任意请求** (CWE-22/CWE-346)
4. **JWT_SECRET使用示例默认值** — 生产环境若未修改可伪造JWT (CWE-798)
5. **users/search为@Public()** — 未认证可搜索获取任意用户email (CWE-200)
6. **CreateUserDto密码仅@MinLength(6)** — 与RegisterDto策略不一致 (CWE-521)
7. **Analytics接受客户端传入ipAddress/userAgent/userId** — 数据可被伪造 (CWE-20)
8. **DownloadRecord接受客户端userId** — 可伪造关联到其他用户 (CWE-20)
9. **exportAnalytics无workspace隔离** — ADMIN可导出全站数据 (CWE-200)
10. **Prisma findUnique软删除失效** — workspace extension覆盖softDeleteExtension的deletedAt过滤 (CWE-200)
11. **Prisma findUnique workspace隔离失效** — 大量Service未手动校验workspace (CWE-284)
12. **lead.findAll未传workspaceId** — ADMIN可看全站线索 (CWE-284)
13. **blog/forum update/delete未校验资源workspace** — 可跨workspace操作 (CWE-284)

### 3.2 后端架构（20项核心）

1. **DTO验证缺失**: blog/forum/cms/lead/analytics/workspace/system/experiment/media/ai等10+模块的内联Body类型无class-validator
2. **分页参数NaN风险**: 所有Controller使用`parseInt(page,10)`内联解析，未用ParseIntPipe
3. **Workspace隔离缺失**: blog-post/forum-topic/media/user Service层未校验workspace归属
4. **RefreshToken过期不一致**: 数据库expiresAt硬编码7天，JWT配置可能不同
5. **SSE内存Map无法集群**: notification.service用内存Map存SSE流，多实例失效
6. **导出全表加载OOM**: export.service无分页直接全表加载生成XLSX
7. **forum-topic无posts分页**: findTopicById返回全部posts，数千回复时OOM
8. **TransformInterceptor误判**: `if('success' in data)`会误伤含success字段的业务数据

### 3.3 前端架构（15项核心）

1. **页面组件未用CSS Modules**: 5个pages/*.vue使用`<style scoped>`
2. **i18n硬编码中文**: Blog/Forum title、NavBar aria-label、AuthModal fallback等20+处
3. **API错误无用户提示**: 页面级组件仅console.error，网络错误时白屏
4. **Icon无法tree-shake**: 80+图标内联在554行组件
5. **图片无懒加载**: BlogListView/BlogDetailView coverImage无loading="lazy"
6. **auth.logout未使token失效**: 未调用后端logout API写入TokenBlacklist
7. **useApiData逻辑错误**: immediate:false时onMounted仍调用load()

### 3.4 数据库（8项核心）

1. **缺失关键索引**: User.roleId、Comment.authorId、Media.createdBy有外键无索引
2. **Token表无限膨胀**: TokenBlacklist/RefreshToken无自动清理机制
3. **Tag全局唯一**: 多租户下workspace A占用tag名后B无法使用
4. **Setting无workspaceId**: 配置全局共享，无法租户级别覆盖

### 3.5 运维部署（10项核心）

1. **CI无安全扫描**: 无npm audit/CodeQL/Trivy
2. **deploy占位符**: master分支通过测试后不自动部署
3. **pnpm/npm混用**: 仓库声明pnpm workspace但CI用npm
4. **无环境变量校验**: ConfigModule无Joi validationSchema
5. **seed.ts硬编码密码**: admin123456直接写在代码中
6. **Nginx缺少安全头**: 无HSTS/CSP/X-Frame-Options
7. **Nginx ssl_ciphers过弱**: HIGH:!aNULL:!MD5过于宽松
8. **Nginx无rate limit**: 无limit_req_zone防DDoS
9. **Redis KEYS命令**: CacheInterceptor用O(N) KEYS导致阻塞
10. **无优雅关闭**: main.ts缺少enableShutdownHooks()

### 3.6 测试（6项核心）

1. **E2E flaky风险**: waitForTimeout(2000)硬编码等待
2. **核心业务流缺失**: 预约演示/搜索/主题切换/语言切换无E2E
3. **无测试数据工厂**: 前后端均无faker工厂
4. **无覆盖率门禁**: 未配置threshold
