# v3.0.0 Sprint 30: 营销闭环实施计划

> **目标**: Demo 预约 → 自动确认邮件 → Admin Lead 追踪
> **时间**: 2 周
> **验收标准**: 提交 Demo 后收到邮件、机器人无法刷表单、Admin 可查看 lead 详情

---

## 任务清单

### Backend

1. **MailModule** — 新建 `modules/mail/`
   - `mail.module.ts` — 注册 MailService
   - `mail.service.ts` — nodemailer 发送 + handlebars 模板渲染
   - 从 `EmailTemplate` 表读取模板，支持变量插值

2. **DemoBooking 邮件触发**
   - `lead.service.ts` — 创建 booking 后，向 BullMQ `notification` 队列添加 `send-email` job
   - 邮件内容：确认预约 + 预计联系时间 + 产品资料链接

3. **Lead 跟进 API**
   - `lead.controller.ts` — `POST /leads/:id/follow-up`
   - `lead.service.ts` — 创建 FollowUp 记录，同时发送邮件给销售团队

4. **reCAPTCHA 验证中间件**
   - `recaptcha.guard.ts` — 验证 Google reCAPTCHA v3 token
   - 应用到 `POST /leads` 和 `POST /auth/register`

### Frontend (Portal)

5. **DemoModal reCAPTCHA**
   - 集成 `vue-recaptcha-v3` 或手动加载 reCAPTCHA script
   - 提交前获取 token，随表单数据发送到后端

### Frontend (Admin)

6. **Lead 详情抽屉**
   - `LeadsView.vue` — 点击行打开抽屉
   - 展示：客户信息、预约产品、历史跟进、状态流转按钮
