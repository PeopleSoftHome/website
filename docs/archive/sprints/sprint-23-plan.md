## 一、背景与动机

v3.2.0 完成后，核心功能和技术债已全部清零。当前聚焦**稳定性**和**体验细节**：

| 维度 | 现状 | 目标 |
|------|------|------|
| PWA | 有 Service Worker 和 Manifest，但无离线页面 | 添加 offline.html + 导航回退 |
| 错误恢复 | 无 Error Boundary，组件错误可能导致白屏 | Vue 错误边界 + 友好降级 |
| E2E 覆盖 | 17 测试，覆盖基本页面加载 | 增加关键交互路径（搜索/主题/表单）|
